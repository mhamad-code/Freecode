# Freecode UI Kit

محتويات الحزمة:

- freecode-ui-prompt.md : برومبت الواجهة الكامل (إنجليزي، 16 جزء + ملحق).
- assets/brand/ : الشعار والأيقونات (tile كامل، mark فاتح، mark غامق، favicon بكل الأحجام).
- references/ : 17 صورة/ملف مرجعي مسماة R01..R17 (نفس الترقيم داخل البرومبت).

طريقة الاستخدام:
1) افتح مشروع جديد عند النموذج البرمجي (Claude Code / Cursor / أي وكيل برمجي).
2) ضع مجلدي assets/ و references/ داخل المشروع (أو ارفع الصور مع الرسالة).
3) الصق محتوى freecode-ui-prompt.md كاملاً، أو على دفعات: الأقسام 0-3 + جزء واحد كل مرة.
4) بعد كل مرحلة قارن الناتج مع الصور المرجعية (قائمة القبول في PART 16).

How to use (EN):
- Put assets/ and references/ in the project folder, then give the model freecode-ui-prompt.md.
- The prompt refers to screenshots by ID (R1..R17) = files in references/.
- Brand files are referenced in section 1.1 of the prompt.
